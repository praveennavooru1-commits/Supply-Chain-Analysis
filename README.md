# Supply-Chain-Analysis
(Data analysis project focused on supply chain performance, inventory, sales, supplier, and delivery insights.)
# About the Project
This project is based on the analysis of supply chain data using Power BI. The main goal was to understand sales performance, inventory levels, supplier performance, and delivery patterns.

I worked with the available data, explored the key metrics, and created an interactive Power BI dashboard to make the information easier to understand and use for decision-making.

# What I Wanted to Analyze
>Sales and overall supply chain performance
>Inventory levels and related trends
>Supplier performance
>Delivery performance
>Important supply chain KPIs
>Areas where performance could be improved

# Tools Used
>Microsoft Power BI
>Data Cleaning and Transformation
>Data Visualization
>KPI Analysis

# Dashboard
The dashboard brings the main supply chain metrics together in one place. It helps to quickly understand sales performance, inventory, supplier performance, and delivery-related trends.

# Key Insights

 I was able to:
>Understand the overall sales and supply chain performance.
>Compare supplier and inventory-related performance.
>Identify important delivery patterns and trends.
>Present the findings in an easy-to-understand Power BI dashboard.

# Conclusion

This project gave me practical experience in using Power BI to work with supply chain data. It helped me understand how data can be cleaned, analyzed, visualized, and presented through an interactive dashboard to support better business decisions.
